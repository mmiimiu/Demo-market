# **App Name**: BaanDee | บ้านดี

## Core Features:

- AI Smart Search Tool: A natural language search tool that allows users to find rentals using intuitive phrases like 'cozy studio near BTS' or 'budget friendly pet house'.
- Instant Dual-Language Toggle: A zero-refresh switcher that transitions the entire interface between Thai and English using specialized font-family swapping.
- Integrated Property Listing Filter: Real-time horizontal filtering tabs and an advanced slider-based drawer for price, area, and amenities.
- Dynamic Property Detail Modal: Overlay gallery with a five-photo strip, interactive maps, and quick-contact triggers without page reloads.
- Rent Affordability Calculator: A dedicated income-to-rent tool that suggests ideal listing price ranges based on user financial input.
- Wishlist Heart System: Persistent favoriting system using local storage to save user preferences across browser sessions.
- Responsive Listing Grid: High-performance property card layout designed for mobile-first scrolling with skeleton shimmer loading states.

## Style Guidelines:

- Primary color: #1A56DB, a deep, professional Royal Blue symbolizing trust and security in the real estate market.
- Background color: #F8FAFF, an extremely clean, crisp light blue-tinted white for maximum readability.
- Accent color: #38BDF8, a vibrant sky blue used for secondary badges, tags, and highlights to keep the UI modern.
- Primary typography recommendation: 'Inter' (sans-serif) for English and numeric content. Secondary font: 'Sarabun' (sans-serif) for Thai content. Note: currently only Google Fonts are supported.
- Minimalist outline icons for property specs (beds, baths, area) and solid icons for UI navigation to differentiate utility.
- A fluid single-page layout featuring a sticky header and horizontal-scrolling 'Quick Filters' to prioritize thumb-friendly mobile navigation.
- Smooth fade-up scroll reveals and side-drawer transitions for the filter engine to maintain a high-end feel.
