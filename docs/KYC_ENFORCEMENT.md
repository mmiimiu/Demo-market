# คู่มือความรัดกุมระบบความปลอดภัย e-KYC (ID Card & Liveness Scan) สำหรับทุกบทบาท

เพื่อแก้ไขปัญหาผู้เช่าค้างชำระเงิน, ละทิ้งห้องพัก, หรือการทำลายทรัพย์สินโดยไม่สามารถติดตามตัวได้ ระบบ **PrimeRent** จึงได้รับการออกแบบมาให้มีกลไกตรวจสอบความถูกต้อง (Security Gate) ที่เข้มงวดสอดคล้องกับทุกบทบาทในแพลตฟอร์ม

ปัจจุบันระบบมีการคุ้มกัน (Guard) ป้องกันไม่ให้ผู้ใช้ที่ยังไม่ยืนยันตัวตนดำเนินธุรกรรมสำคัญ ดังนี้:

---

## 🛡️ 1. สำหรับผู้เช่า (Tenant/Renter)
* **กลไกการล็อก:** ผู้เช่าจะ **ไม่สามารถลงลายมือชื่อในสัญญาเช่าดิจิทัลได้** หากสถานะ KYC ยังไม่เป็น `verified`
* **ตำแหน่งโค้ดตรวจสอบ:** [SignaturePadModal.tsx (บรรทัดที่ 99-113)](file:///d:/renter---feature-primerent-v2-notifications-rolefilter/renter---feature-primerent-v2-notifications-rolefilter/src/components/contract/DigitalContractView/SignaturePadModal.tsx#L99-L113)
* **การแสดงผล:** หากยังไม่ได้อัปโหลดบัตรประชาชนและสแกนใบหน้า ระบบจะปิดกั้นหน้าจอเซ็นสัญญา และแสดงปุ่มนำทางให้ผู้เช่าเข้าไปดำเนินการยืนยันตัวตนในโปรไฟล์ให้เสร็จสิ้นก่อนลงนาม

---

## 🏡 2. สำหรับเจ้าของห้อง (Owner/Landlord) และเอเจ้นต์ (Agent)
* **กลไกการล็อก:** เจ้าของห้องและเอเจ้นต์จะ **ไม่สามารถลงประกาศห้องเช่าใหม่เข้าสู่ระบบได้** หากไม่ผ่านการยืนยันประวัติอาชญากรรมและการตรวจสอบตัวตน
* **ตำแหน่งโค้ดตรวจสอบ:** [PostListingPage (บรรทัดที่ 104-150)](file:///d:/renter---feature-primerent-v2-notifications-rolefilter/renter---feature-primerent-v2-notifications-rolefilter/src/app/post-listing/page.tsx#L104-L150)
* **การแสดงผล:** ระบบจะแสดงบล็อกหน้าจอความปลอดภัยแจ้งว่า *"จำเป็นต้องยืนยันประวัติอาชญากรรม (CRD)"* และไม่อนุญาตให้กรอกข้อมูลห้องเช่าใดๆ จนกว่าจะยืนยันตัวตนผ่านระบบ e-KYC เรียบร้อย

---

## ⚙️ 3. การกู้คืนระบบและการตั้งค่าคัดกรองเพิ่มระดับความรัดกุม
หากต้องการให้ระบบมีความเข้มงวดมากขึ้นในอนาคต เช่น การล็อกไม่ให้อ่านรายละเอียดประกาศ หรือการบล็อกตั้งแต่การส่งแชทสนทนา สามารถใช้เมธอดตรวจประวัติจากสโตร์ในทุกคอมโพเนนต์ย่อยได้ดังนี้:

```typescript
import { useAdminStore } from '@/hooks/useAdminStore';

// ดึงสถานะ KYC ของผู้ใช้งานมาเช็ค
const kycStatus = localStorage.getItem('primerent_mock_kyc') || 'unverified';
const isVerified = kycStatus === 'verified';

if (!isVerified) {
  // บล็อกการคลิก หรือนำทางไปยังหน้า e-KYC
}
```
